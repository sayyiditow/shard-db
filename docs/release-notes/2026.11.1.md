# shard-db 2026.11.1

2026.11.1 continues the R4 strict scalar grammars with the R5 packed-layout
work: the `layout=packed` token on an object's `schema.conf` line becomes the
authoritative object layout (a malformed token fails the load; there is no
legacy fallback), and the first start of this release migrates every object
to the packed layout before serving. Upgrading requires a **cleanly stopped
2026.10.2 root** — start 2026.10.2 against the DB_ROOT, stop it cleanly,
then upgrade; 2026.11.1 refuses an unclean root or a root with pending
commit markers and tells you so.
